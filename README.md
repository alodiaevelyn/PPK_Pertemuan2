| Kode | Deskripsi | Acceptance Criteria |
|------|-----------|---------------------|
| **SRS-001** | Membuat dan mengatur daftar/project tugas | - Pengguna dapat membuat daftar/project<br>- Pengguna dapat mengelompokkan tugas ke dalam daftar/project |
| **SRS-002** | Menambahkan pengguna ke dalam daftar tugas | - Pemilik daftar dapat menambahkan pengguna lain<br>- Pengguna yang ditambahkan dapat mengerjakan tugas bersama |
| **SRS-003** | Menentukan prioritas dan waktu tugas | - Pengguna dapat menetapkan prioritas tugas<br>- Pengguna dapat menentukan waktu tugas |
| **SRS-004** | Menandai tugas sebagai selesai | - Pengguna dapat menandai tugas yang telah selesai<br>- Status tugas menunjukkan bahwa tugas telah selesai |
| **SRS-005** | Memantau progres tugas | - Pemilik daftar dapat memantau progres penyelesaian tugas dalam daftar |
| **SRS-006** | Manajemen akun pengguna oleh admin | - Admin dapat menambahkan akun pengguna<br>- Admin dapat menghapus akun pengguna |
